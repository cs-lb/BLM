## 版本 A：个人项目口径（当前证据完全支持）

**风控视觉基座（BLM ViT）复现与工程实现｜个人项目｜2026.08**  
技术栈：PyTorch / Qwen2.5-VL-7B / BGE-M3 / SigLIP / DDP / vLLM / YOLO-World  
代码开源：github.com/cs-lb/BLM（4 个子工程，约 4500 行）

- **复现工业级视觉基座预训练框架**：Qwen2.5-VL-7B 视觉塔 + BGE-M3 文本塔 + SigLIP 损失的双塔架构；自主实现动态分辨率数据通路（smart_resize 保长宽比、官方对齐的 patch 重排、batch 内 packing 零 padding）与数据侧 binpack（在线贪心/离线全局装箱两策略，实测 9.9 万样本装箱填充率 89.7%）；双卡 4090 上完成真实训练，loss 从 10.6（负偏置主导的随机基线）稳定降至 3.3（100 步），τ/b 可学习标量轨迹符合 SigLIP 理论预期。
- **实现多卡负例同步并修复变长装箱下的分布式 bug**：自定义 autograd Function 实现 all_gather 全局 embedding + 梯度只回本卡份（数学上与全 batch 单卡严格等价）；**发现 binpack 各 bin 图片数不齐导致 NCCL all_gather 必崩的问题**，重写为变长 gather（counts 交换 + 零填充 + key mask 剔除，数值验证填充不影响损失）；编写分布式探针（变长 gather / mask / 梯度逐元素一致性 / 参数不发散四重校验）实证同步正确。
- **构建 10 万级中文图文数据管线**：wukong100m（1 亿 URL 的 32 分片 parquet）并发下载（实测成功率 60% 下的 1.7× 冗余容错）、caption 清洗、sha1 字节级去重、断点续跑（sha1 文件名即状态，中断后已有数据自动收养复用）；binpack token 统计磁盘缓存（二次启动秒读）。
- **实现 FG-CLIP 式细粒度图文对齐子工程**：五步数据生产线（MLLM dense caption → SpaCy 引用表达式抽取 → YOLO-World 开放词汇定位（NMS + 0.4 阈值、无框丢弃）→ 颜色>动作>数量>材质优先级难负例改写）+ 区域级三损失（全局 InfoNCE + 区域 InfoNCE + 难负例 margin 损失，merger 前 patch token 网格池化提取区域特征）。
- **设计 v1→v2 风险语义精修方案并实现训练工程**：三元损失（batch-hard，margin=0.2）管相对排序 + MSE 蒸馏管绝对标定（教师 BGE-VL-v1.5-mmeb 与学生同余弦度量空间，直接对标定余弦值 MSE），修复三元损失"比烂"漏洞；难负例四通道挖掘体系（LLM 版本分歧 / KNN 近邻 / 负例相似 / **线上人工审核错误召回的数据飞轮**）。
- **沉淀通用批量 VLM 推理基建**（vlm_batch）：vLLM 离线批 / DashScope API / transformers 三后端，缓存断点（key=图+任务+prompt版本，换 prompt 自动失效）、失败隔离与定点重试；复用于飞轮 caption、72B 候选生成、裁判打标三条数据生产线。
- **独立排查多个真实工程 bug**：transformers 5.x 三处兼容问题（视觉塔返回结构变更需取 merger 后 pooler_output、bf16 原生权重与 fp32 投影层 dtype 冲突、视觉塔类名变更）；MPS 平台 int64 不支持（统一降级 int32）；数据下载线程池百万 future 提前退出死等（改分块提交）；DDP+梯度检查点需 use_reentrant=False。沉淀"不训练的形状断言链路测试"方法论。

## 追问预案（每条 bullet 的深挖问题 + 证据口径）

| Bullet  | 面试官可能追问                    | 应答要点（均有代码/实测支撑）                                                                                                    |
| ------- | -------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| 预训练框架   | 为什么 SigLIP 不选 InfoNCE？     | 逐对 sigmoid 独立，无需全 batch softmax 归一 → 多卡每卡只算本地 query 行；小 batch 鲁棒；负偏置 b=−10 防负对初期梯度消失（实测随机 loss 10.6、完美对齐 ln2≈0.69） |
| 预训练框架   | packing 和 binpack 区别？      | packing 治 batch 内 padding（cat+cu_seqlens 块对角，省 43.5%）；binpack 治 step 间 token 波动（数据侧装箱，填充率 ≥95%，DDP 各卡时间对齐）         |
| 负例同步    | 梯度为什么是对的？                  | 前向本卡位换回带图真身、反向切回本卡行；SigLIP 逐对独立使本地行计算精确；变长 gather 的 mask 保证填充零贡献；探针 check3 两卡梯度逐元素一致                               |
| 负例同步    | 是严格等价还是近似？                 | local_loss 变体：query 侧完整、key 侧缺跨卡部分；open_clip 同款权衡，省一半矩阵计算；能讲清这个 trade-off 是加分项                                     |
| 数据管线    | 成功率 60% 怎么办？               | 1.7× 冗余拉取 + sha1 去重 + 断点续跑（状态外化到产物，输出文件即断点账本）                                                                      |
| FG-CLIP | 区域特征怎么提？                   | merger 前 token（last_hidden_state，1280 维）reshape (gh,gw,D) 网格 + bbox 矩形池化 + 独立 region_proj；零额外检测主干                  |
| v1→v2   | 为什么三元+MSE 缺一不可？            | 三元只管相对排序（"比烂"漏洞：s_p=−0.2, s_n=−0.5 也满足 margin）；MSE 蒸馏把教师绝对相关性灌进来；只蒸馏则难负例间精细 margin 学不到且教师错误传染                      |
| v1→v2   | 教师为什么选 BGE-VL 而非 reranker？ | reranker 是纯文本 cross-encoder 无法给图-文打分；BGE-VL 与学生同余弦空间，MSE 量纲自洽，无需分数对齐层                                              |
| 难负例     | 四通道分别解决什么？                 | 三个离线通道冷启动 + 线上飞轮通道持续造血：模型在哪错就补哪，审核员纠正同时产出正例，系统上线后负例自增长                                                             |
| 排错      | 怎么发现这些 bug 的？              | 不训练的链路专项测试（随机小 batch 验形状断言：拼接行数=Σgh·gw、池化边界=t·gh·gw/4、L2 范数=1、未训练 diag≈offdiag）；训练期用 loss≈ln(N)/10.6 基线验证          |

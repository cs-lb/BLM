blm_siglip 模型结构详解

BLMSiglipModel = Qwen2.5-VL-7B 视觉塔 + BGE-M3 文本塔 + 双侧投影层 + SigLIP 双标量。总参数 ~1.24B，代码位于 blm_siglip/blm_siglip/models.py。

0架构总览：双流编码 + 共享嵌入空间

视觉流（~675M 参数）

pixel_values [Σpatches, 1176] packing 拼接
Conv3d(3→1280, k=2×14×14) patch 嵌入
mRoPE 2D 位置编码 按图独立生成
32 × VisionBlock 窗口注意力 × 28 + 全局 × 4
PatchMerger 2×2 合并 → MLP → 3584
逐图均值池化 按 grid_thw 边界切分
proj: Linear(3584→1024) 共享空间投影
L2 normalize 单位向量 img_z

文本流（~568M 参数）

input_ids [B, ≤96] SentencePiece 分词
Embedding(250002→1024) XLM-R 词表
24 × TransformerEncoderLayer pre-norm, padding mask
CLS 位取值 BGE dense 检索标准池化
proj: Linear(1024→1024) 共享空间投影
L2 normalize 单位向量 txt_z
τ = exp(ln10), b = −10 SigLIP 可学习标量
logit = τ·(img_z·txt_zᵀ)+b 逐对 sigmoid 损失
结构设计的三条原则：① 双塔全部使用预训练权重（QwenViT 懂视觉、BGE-M3 已在检索友好空间），对比学习只做"空间对齐"；② 两侧通过各自投影层进入同一 1024 维单位球面，相似度才有可比性；③ 可学习参数只有双塔 + 两个 Linear + 两个标量，没有引入任何新结构。

1视觉塔：Qwen2.5-VL-7B 的 ViT（~675M）

1.1 逐层结构

层级结构作用与备注
Patch 嵌入Conv3d(3→1280, kernel=stride=(2,14,14))每个 14×14 patch（temporal 复制 2 帧）→ 1280 维 token；输入是我们 data.py 重排好的 [Σpatch, 1176]
位置编码mRoPE（2D 旋转位置编码）按每图自己的 grid_thw 从 (0,0) 独立生成——packing 可行的前提
主干32 × VisionBlock（hidden 1280, 16 heads, FFN 3420）28 层窗口注意力（112×112px = 8×8 patch 窗口，window index 重排）+ 4 层全局注意力（第 7/15/23/31 层）补全局视野
图间隔离cu_seqlens 分段注意力由 grid_thw 推出边界，flash-attn varlen 只算块对角，packing 的图互不可见
MergerLayerNorm + MLP(5120→5120→3584)2×2 patch 合并：token 数 ÷4，维度 1280→3584（= 7B LLM 的 hidden）
逐图池化（我们加的）split + mean按 t·gh·gw/4 边界切回每图，均值池化为 [B, 3584]
投影层（我们加的）Linear(3584→1024, bias=False)映射到共享嵌入空间
merger 前后别拿错（transformers 5.x 的坑，已踩过）：last_hidden_state = merger 前（Σgh·gw 个 token，1280 维）；pooler_output = merger 后（Σgh·gw/4 个，3584 维）。全局表征取后者；FG-CLIP 区域特征才用前者。

2文本塔：BGE-M3（~568M）

属性值说明
基座XLM-RoBERTa-large24 层 Encoder，hidden 1024，16 heads，FFN 4096
词表250,002（SentencePiece）多语言 BPE；与 Qwen 分词器不同体系，严禁混用
上下文8192 tokencaption 场景（中位 24 字）远用不满，为后续审核规则长文本留空间
池化CLS 位（last_hidden_state[:, 0]）BGE-M3 dense 检索的标准取法
投影Linear(1024→1024, bias=False)进共享空间（宽度不变，学"面向风控语义的旋转"）
为什么选 BGE-M3 而不是从零训练/从 Qwen 初始化：它本身就是为检索对比任务预训练好的文本编码器，语义空间天然适合余弦检索——这正是 LiT 失败教训的正面应用（冻结/使用一个已在对比空间的塔是有效的，前提是该空间真的检索友好）。
class BgeM3TextTower(nn.Module):
    def __init__(self, model_name, embed_dim):
        self.backbone = AutoModel.from_pretrained(model_name)   # hidden=1024
        self.proj = nn.Linear(self.backbone.config.hidden_size, embed_dim, bias=False)

    def forward(self, input_ids, attention_mask):
        out = self.backbone(input_ids=input_ids, attention_mask=attention_mask)
        cls = out.last_hidden_state[:, 0]      # CLS 位：整句向量
        return self.proj(cls)

3投影层与 SigLIP 双标量

class BLMSiglipModel(nn.Module):
    def __init__(self, cfg):
        self.visual = QwenViTVisionTower(...)      # 含 proj(3584→1024)
        self.text = BgeM3TextTower(...)            # 含 proj(1024→1024)
        # SigLIP 双标量（SigLIP 论文口径；weight_decay=0）：
        self.logit_scale = nn.Parameter(torch.tensor(math.log(10.0)))  # 存 ln τ
        self.logit_bias  = nn.Parameter(torch.tensor(-10.0))          # b=−10 负偏置
  • 为什么存 ln τ 而不是 τ：对数参数化保证 τ>0 恒成立，且梯度尺度稳定（CLIP/SigLIP 惯例）。
  • b=−10 的力学：矩阵里负对远多于正对，负偏置让初始 logits 偏负，正对需"爬坡"，防止负对被过早压到 σ≈1 后梯度消失。训练轨迹：τ 缓升（正负分离加剧）、b 从 −10 回升（爬坡完成后偏置需求降低）。
  • L2 归一化在 encode_* 里完成：点积 = 余弦相似度，且把 logit 限制在 [−τ+b, τ+b] 的有界区间。

5前向完整代码（含形状注释）

def encode_image(self, image_inputs):
    # qwenvit 路径：image_inputs = (pixel_values [Σpatch,1176], grid_thw [B,3])
    z = self.visual(*image_inputs) if isinstance(image_inputs, (list, tuple)) \
        else self.visual(image_inputs)
    # 视觉塔内部：Conv3d → 32 blocks(cu_seqlens 分段) → merger →
    # 按 t·gh·gw/4 逐图切分 → 均值池化 [B,3584] → proj → [B,1024]
    return F.normalize(z, dim=-1)          # [B,1024] 单位向量

def encode_text(self, input_ids, attention_mask):
    # BGE-M3 → CLS [B,1024] → proj → normalize
    return F.normalize(self.text(input_ids, attention_mask), dim=-1)

def forward(self, batch):
    img_z = self.encode_image(batch["image_inputs"])          # [B,1024]
    txt_z = self.encode_text(batch["input_ids"], batch["attention_mask"])
    # 返回给 SiglipLoss：logit = exp(logit_scale)·(img_z@txt_zᵀ) + logit_bias
    return img_z, txt_z, self.logit_scale, self.logit_bias

6优化器参数分组（判别式学习率）

def param_groups(self, lr_vision, lr_text, lr_proj, weight_decay):
    groups = [
        {"params": [p for p in self.visual.parameters() if p.requires_grad],
         "lr": lr_vision, "weight_decay": weight_decay, "name": "vision"},      # 1e-5, wd 0.2
        {"params": list(self.text.parameters()),
         "lr": lr_text, "weight_decay": weight_decay, "name": "text"},          # 1e-5, wd 0.2
        {"params": [self.logit_scale, self.logit_bias],
         "lr": lr_proj, "weight_decay": 0.0, "name": "siglip_scalars"},          # 5e-5, wd 0
    ]
    return [g for g in groups if len(g["params"]) > 0]
设计逻辑：双塔预训练权重给 1e-5（保护表征，防业务数据冲毁）；两个 proj 是新参数需 5e-5 从头学；τ/b 是尺度型标量，weight_decay 必须为 0——否则 wd 会把 τ 往 0 拉、把 b 往 0 推，人为扭曲温度语义。冻结场景（freeze_vision=true）时空组会被自动过滤。

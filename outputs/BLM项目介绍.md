# 风控大模型（BLM）项目介绍

> 版本：v1.0｜范围：项目全景 + 视觉头（BLM ViT）训练方案详述
> 关键词：SigLIP / 动态分辨率 / binpack / 多卡负例同步 / FG-CLIP / 三元损失 / MSE 蒸馏 / LLM-as-a-Judge

---

## 1. 项目背景

商业化内容平台每天产生海量图文内容，传统审核依赖"固定类别分类模型 + 人工复审"，面临三个结构性问题：

1. **违规模式持续演化**：新的风险形态（新型导流话术、变体二维码、擦边内容）层出不穷，固定类别范式无法覆盖开放风险空间；
2. **通用模型不懂风控**：开源 CLIP 类模型的嵌入空间没有风控语义结构——同类风险内容不聚拢，且固定 224 分辨率对小区域违规（角落二维码、一闪而过的违规帧）天然不友好；
3. **审核语义是"规则文本"**：审核判定的本质是"图片 vs 拒绝理由（规则文本）"的相关性判断——这天然是一个**跨模态检索/对齐问题**，需要一个懂风控语义的视觉基座。

因此团队启动风控大模型（BLM）项目：以多模态大模型为主干，构建"视觉基座预训练 → MLLM 训练 → 图搜文 Copilot / 智能审核"的完整链路。

## 2. 项目目标

**总目标**：训练一个注入风控领域知识的多模态基座，使"风险图片 ↔ 拒绝理由"在同一嵌入空间内可检索、可推理，支撑下游审核 Copilot 与自动化判责。

**本阶段（我负责的部分）目标**：训练视觉基座 **BLM ViT**——
- v1：大规模自监督对比学习，让通用语义 + 业务视觉知识进入 QwenViT；
- v2：两个方向的精修——**细粒度对齐**（看得清局部细节）与**风险语义对齐**（图片与拒绝理由的相关性），最终在业务图搜文检索上达到 **hit@5 97%**。

## 4. 阶段一：大规模 SigLIP 自监督预训练（v1）

### 4.1 数据

| 数据集 | 角色 | 配比 | 处理 |
|---|---|---|---|
| Wukong100m（中文） | 公共主力 | 60% | parquet 分片（URL+文本）→ 并发下载（成功率 ~60%，1.7× 冗余） |
| LAION-5B 中文子集 | 公共多样性 | 20% | metadata + 按 URL 下载 |
| 业务封面 + 飞轮 caption | 领域注入 | 20% | Qwen2.5-VL 飞轮刷 caption；不足时**重复采样等价混入**，不降公共占比 |

清洗四步：caption 清洗（5~200 字）→ 图片校验（≥64px/≥5KB/可解码）→ **sha1 字节级去重**（防重复图成为"最难负例"虚抬指标）→ **先 shuffle 再切分**（防 train/eval 近邻泄漏）。

### 4.2 模型与损失

- **视觉塔**：Qwen2.5-VL-7B 的 ViT（675M）。选它的三个理由：mRoPE 2D 位置编码原生支持动态分辨率与 packing；窗口注意力计算量可控；与下游 Qwen 系 MLLM 同源。工程上把视觉权重从 15GB 全模中单独抽取（1.26GB，秒级加载）。
- **文本塔**：BGE-M3（568M，XLM-R-large）。它本身是为检索对比任务训练的编码器，**语义空间天然检索友好**——避免了"从零训练文本塔同时学语言+学对齐"的小数据瓶颈。CLS 池化。
- **损失：SigLIP**（而非 InfoNCE）。把 N×N 相似度矩阵的每格当独立二分类：logit = τ·cos + b，L = −log σ(z·logit)。τ init 10、b init −10（负偏置防止负对初期梯度消失）。相对 InfoNCE 的工程红利：**逐对独立、无需全 batch softmax 归一**，多卡下每卡只算本地 query 行即可；小 batch 更鲁棒。

### 4.3 动态分辨率三件套（训练效率的核心）

1. **smart_resize**：图片按长宽比缩放到 28 的倍数且 token 预算内（128~448 merged token），保留长宽比不失真；
2. **packing（batch 内）**：所有图的 patch 直接拼接成长序列，grid_thw 推出 cu_seqlens 做块对角注意力——零 padding 浪费（典型场景省 43.5% 算力）；
3. **binpack（step 间）**：数据侧按 token 数装箱，每桶 token ≈ bin_token（业务在线贪心 / 开源离线全局装箱），保证每步算力恒定——显存可预测、DDP 各卡 step 时间对齐。bin_token 按显存反推（448×N，N=每张卡预算的最大图数）。

### 4.4 多卡负例同步

对比学习效果强依赖负例数。DDP 下各卡独立编码本地 bin，loss 前 **all_gather 全局 embedding**（自定义 autograd：前向汇集后本卡位换回带计算图真身，反向只切回本卡梯度），负例数 ×卡数。通信量仅 N×1024×2B 级可忽略。binpack 各 bin 图片数不同，实现为**变长 gather**（交换 counts → 零填充 → mask 剔除无效 key 列）。

### 4.5 训练配置与产物

AdamW(β=0.9/0.98) + warmup/cosine；判别式 LR（双塔 1e-5 保护预训练表征、投影与标量 5e-5 且免 wd）；bf16 + 梯度检查点；梯度累积补有效 batch。
产物：BLM ViT v1 checkpoint + metrics.jsonl（loss/τ/b/grad_norm 全程轨迹）+ 周期检索评估（hit@5）。

## 5. 优化点一：细粒度图文对齐（FG-CLIP，~20w 数据）

**动机**：全局 CLIP 只优化整图与整句的对齐——模型学到"这是只猫"即可分开正负样本，"白猫黑猫、跳还是卧"对 loss 无影响，属性/区域信号被全局池化平均掉。对审核场景（小区域违规）这是硬伤。

**方案（五步数据生产线 + 区域级损失）**：

```
详细描述（MLLM dense caption）→ 引用表达式抽取（SpaCy 名词短语+修饰语过滤）
→ YOLO-World 开放词汇定位（NMS + 置信度>0.4，无框丢弃）
→ 难负例构造（保留核心对象，颜色>动作>数量>材质单属性改写："白猫"→"金猫"）
→ 区域级三损失联合训练
```

- **区域特征**：不引入额外检测主干，直接在 ViT merger 前的 patch token 上做 bbox→网格映射池化 + region_proj，与全局共享嵌入空间；
- **损失**：L = L_global + 0.5·L_region（区域-表达式 InfoNCE）+ 1.0·L_hard（难负例 margin 损失 mean(max(0, 0.2 + cos(r,e_hard) − cos(r,e_pos)))）；
- **护栏**：训练中周期监控全局 hit@5 不回退，λ_region 小步 warmup。

（详细方案见《细粒度图文对齐详解》文档。）

## 6. 优化点二：三元损失 + MSE 蒸馏的风险语义对齐（v2 主线）

### 6.1 数据从哪来（数据生产线）

正负样本对（一张图 ↔ 若干相关/不相关的拒绝理由）是这条线的燃料，生产链路：

```
Qwen2.5-VL 72B + PE ──生成──> 1w 风险图-拒绝理由候选对（每图 5~7 个理由，混入无关项）
        │
        ├─> 人类专家精标 2000+ 对 ──LoRA 微调──> Judged MLLM v2（Qwen2.5-VL 32B）
        │        ▲ 提质四件套：few-shot CoT（防假相关）/ bad case 补 few-shot /
        │        │            多 Judge 集成投票 / 低 T + 明确判定标准
        │        └─ 500 条人标验证，人机一致率对齐至 95% 才放量
        ▼
原始正负样本对（相关/不相关）
        ▼ 难负例四通道挖掘
  ① LLM 挖掘：v1 判正 v2 判负的版本分歧样本
  ② KNN 挖掘：嵌入近邻但理由不相关
  ③ 负例相似挖掘：与正例理由文本相似但不相关
  ④ 数据飞轮挖掘：人工审核时系统召回的错误答案即为天然难负例
     （线上真实检索错误），审核员同时人工标注正确正例——
     最难负例质量最高的通道，且随系统上线持续自增长
```

> 通道④的独特价值：前三个通道是"离线构造"（可能造出脱离真实分布的负例），
> 通道④的难负例来自**线上真实召回错误**——模型在哪里错，就精准补哪里；
> 且审核员的纠正标注同时产出正例，形成"错误召回 → 人工纠正 → 进训练集 →
> 模型变强 → 新的更难错误"的自增强飞轮。

### 6.2 损失设计：相对排序 + 绝对标定

**三元损失（margin）**：对人工/裁判指定的正负样本对，用余弦相似度作距离，
L = mean(max(0, m + cos(a, n_hard) − cos(a, p)))，取 batch 内最难负例。
它只约束**相对距离**（正比负近一个 margin），存在**"比烂"漏洞**：
正负样本相似度可以都很低、只要负的更低即达标——绝对标定缺失，下游按阈值召回会失效。

**MSE 蒸馏（修"比烂"）**：引入开源多模态编码器 **BGE-VL-v1.5-mmeb** 作为教师——
它与学生一样是双塔余弦空间，**同度量空间下直接对学生与教师的余弦值做 MSE**，
把"这张图和这条理由到底有多相关"的绝对知识灌进 ViT：

```
教师：cos_teacher = BGE-VL(图) · BGE-VL(文)        （绝对相关性标定）
学生：cos_student = ViT(图) · TextTower(文)
L_mse = mean( (cos_student − cos_teacher)² )        （可选：教师置信度加权）
L_total = λ_triplet · L_triplet + λ_mse · L_mse
```

**两者缺一不可**：只三元损失 → "比烂"漏洞、绝对标定缺失；只 MSE 蒸馏 →
教师分数粗粒度，同一 anchor 下难负例间的精细 margin 学不到，且教师错误无约束传染。
三元管"排得对"，蒸馏管"标得准"。

### 6.3 训练配置

从 v1 checkpoint 继续：双塔 LR 再降一档（5e-6 精修）、margin=0.2、λ_triplet=1.0 / λ_mse=0.5
（教师噪声大时降到 0.2~0.3）；难负例优先（教师分高的负例排前）；产出 **BLM ViT v2**。

## 7. 评估体系

| 层级 | 指标 | 口径 |
|---|---|---|
| 检索主指标 | **hit@5（图搜文 R@5）** | 业务封面检索拒绝理由/描述，v2 目标 97% |
| 对称指标 | t2i R@1/5/10 | 监控通用检索能力不回退 |

| 嵌入结构 | t-SNE 按风险类目着色 | 同类风险可见聚簇 |
